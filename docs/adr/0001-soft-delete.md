# 글·댓글은 소프트 삭제한다

글과 댓글 삭제는 DB에서 행을 지우지 않고 `deleted` 플래그만 켜서 숨긴다(소프트 삭제). 글을 삭제해도 달린 댓글·대댓글은 그대로 유지되고, 댓글을 삭제해도 그 대댓글은 유지된다. 이력 보존과 추후 복구 가능성을 위해 하드 삭제(단순하지만 비가역) 대신 선택했다.

## Consequences

- 모든 글/댓글 조회 쿼리는 `deleted = false` 조건을 일관되게 적용해야 한다. 누락 시 삭제된 항목이 노출된다.
- 추천수·조회수 집계, 목록 페이징도 삭제된 항목을 제외해야 한다.
- 삭제된 글의 댓글은 글이 숨겨져 접근 경로가 없으므로 별도 처리 없이 함께 가려진다.
