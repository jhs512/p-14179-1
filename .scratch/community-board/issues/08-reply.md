# 대댓글 (1단계)

Status: ready-for-agent

## Parent

`.scratch/community-board/PRD.md`

## What to build

댓글에 답하는 대댓글(Reply). 로그인 회원이 특정 최상위 댓글에 대댓글을 달면 부모 댓글을 참조하는 `Comment`로 저장되고, 상세에서 부모 아래 계층으로 표시된다. 중첩은 1단계까지만 — 대댓글(이미 부모가 있는 댓글)에는 다시 대댓글을 달 수 없다(거부). 부모가 될 수 있는 것은 최상위 댓글뿐이다.

## Acceptance criteria

- [ ] 최상위 댓글에 대댓글을 달면 부모를 참조해 저장된다
- [ ] 상세에서 대댓글이 부모 댓글 아래에 표시된다
- [ ] 대댓글에 다시 대댓글을 시도하면 거부된다(1단계 제한)
- [ ] 미인증 대댓글 작성은 로그인으로 리다이렉트된다
- [ ] MockMvc 테스트: 대댓글 작성·계층 표시, 2단계 중첩 거부를 검증한다
