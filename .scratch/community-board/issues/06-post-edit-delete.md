# 글 수정·삭제 (소프트 삭제·권한)

Status: ready-for-agent

## Parent

`.scratch/community-board/PRD.md`

## What to build

글의 수정·삭제. 작성자 본인 또는 `ADMIN` role 회원만 수정·삭제할 수 있다. 수정은 제목·내용을 갱신한다. 삭제는 하드 삭제가 아니라 `deleted=true` 소프트 삭제(ADR-0001)이며, 삭제 후 글은 목록·상세에서 사라지되 달린 댓글·대댓글은 데이터로 유지된다(접근 경로 없음). 권한 없는 회원의 수정·삭제 시도는 거부된다.

## Acceptance criteria

- [ ] 작성자 본인이 글을 수정하면 제목·내용이 갱신된다
- [ ] `ADMIN`은 임의의 글을 수정·삭제할 수 있다
- [ ] 작성자/ADMIN이 아닌 회원의 수정·삭제는 거부된다(403 또는 동등)
- [ ] 삭제는 `deleted=true`로 처리되고 DB 행은 남는다
- [ ] 삭제된 글은 목록·상세에서 사라지고 댓글 데이터는 유지된다
- [ ] MockMvc 테스트: 본인 수정/삭제, ADMIN 수정/삭제, 타인 거부, 소프트 삭제 가시성을 검증한다
