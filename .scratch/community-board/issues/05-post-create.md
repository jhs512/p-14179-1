# 글 작성

Status: ready-for-agent

## Parent

`.scratch/community-board/PRD.md`

## What to build

로그인 회원이 제목·내용으로 새 글을 작성하는 흐름. 작성 폼 페이지 → POST → 검증 → 현재 로그인 회원을 작성자로 `Post` 저장 → 작성된 글 상세로 리다이렉트. 미인증은 로그인으로 리다이렉트.

## Acceptance criteria

- [ ] 로그인 회원에게 글 작성 폼이 보인다
- [ ] 제목·내용 제출 시 현재 회원을 작성자로 글이 저장된다
- [ ] 작성 후 해당 글 상세로 이동하고 목록 최상단에 노출된다
- [ ] 빈 제목/내용은 Validation으로 거부된다
- [ ] 미인증 사용자는 작성 폼·작성 요청에서 로그인으로 리다이렉트된다
- [ ] MockMvc 테스트: 인증 작성 성공, 미인증 리다이렉트, 검증 실패를 검증한다
