# 추천 토글 (글·댓글)

Status: ready-for-agent

## Parent

`.scratch/community-board/PRD.md`

## What to build

회원이 글·댓글에 추천을 표하는 토글 기능. `Recommendation`(추천 회원 + 대상(Post 또는 Comment))을 정의하고 회원당 대상당 유니크 제약을 둔다. 추천이 없으면 생성(+1), 이미 있으면 삭제(-1)하는 토글. 본인이 작성한 글·댓글에는 추천 불가(거부). 글·댓글 상세에 추천수(= 대상의 Recommendation 개수)가 표시된다. 소프트 삭제된 대상은 집계에서 제외.

## Acceptance criteria

- [ ] 회원이 글/댓글을 추천하면 Recommendation이 생성되고 추천수가 1 증가한다
- [ ] 같은 대상을 다시 누르면 추천이 취소되고 추천수가 1 감소한다(토글)
- [ ] 회원당 대상당 추천은 최대 1개(유니크)다
- [ ] 본인이 작성한 글·댓글 추천은 거부된다
- [ ] 미인증 추천은 로그인으로 리다이렉트된다
- [ ] 추천수가 글·댓글에 표시되고 삭제된 대상은 집계되지 않는다
- [ ] MockMvc 테스트: 추천/취소 토글, 유니크, 본인 추천 거부, 미인증 리다이렉트를 검증한다
