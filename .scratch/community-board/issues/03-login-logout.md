# 로그인/로그아웃

Status: ready-for-agent

## Parent

`.scratch/community-board/PRD.md`

## What to build

Spring Security 폼 로그인 + 세션 기반 인증. 로그인 페이지에서 `username`·`password`로 인증하면 세션이 생성되고, 로그아웃하면 세션이 종료된다. 인증이 필요한 작업(작성·수정·삭제·추천 등)에 미인증으로 접근하면 로그인 페이지로 리다이렉트된다. 헤더 등에 로그인 상태(닉네임/로그아웃 링크)가 반영된다.

## Acceptance criteria

- [ ] 올바른 자격증명으로 로그인하면 인증 세션이 생성된다
- [ ] 틀린 자격증명은 거부되고 에러가 표시된다
- [ ] 로그아웃 시 세션이 무효화된다
- [ ] 미인증 사용자가 보호된 경로 접근 시 로그인 페이지로 리다이렉트된다
- [ ] 레이아웃에 로그인/비로그인 상태가 다르게 표시된다
- [ ] MockMvc 테스트: 로그인 성공/실패, 로그아웃, 보호 경로 리다이렉트를 검증한다
