# 조회수 (24시간 유니크)

Status: ready-for-agent

## Parent

`.scratch/community-board/PRD.md`

## What to build

글 상세 조회 시 조회수 누적. 로그인 회원이 글 상세에 진입하면, 해당 회원·글의 마지막 조회시각이 없거나 24시간을 초과한 경우에만 `viewCount`를 +1 하고 조회시각을 갱신한다(시간창 내 재방문은 증가 없음). 비로그인 진입은 카운트하지 않는다. 회원·글 단위 마지막 조회시각을 추적하는 저장소(`PostViewLog` 등, 조합당 1행 유지)를 둔다. OSIV가 꺼져 있으므로 조회 + 증가를 상세 조회 액션 메서드의 단일 트랜잭션 안에서 처리한다.

## Acceptance criteria

- [ ] 로그인 회원의 첫 상세 진입 시 viewCount가 +1 된다
- [ ] 같은 회원이 24시간 내 재진입하면 증가하지 않는다
- [ ] 24시간 초과 후 재진입하면 다시 +1 된다
- [ ] 비로그인 진입은 viewCount를 증가시키지 않는다
- [ ] 회원·글 조합당 마지막 조회시각이 1행으로 유지·갱신된다
- [ ] MockMvc 테스트: 첫 진입 증가, 시간창 내 미증가, 시간창 초과 재증가, 비로그인 미카운트를 검증한다(시간은 주입 가능한 시계로 제어)
